# Council of Rome Plugin

Five Roman magistrate evaluation skills for Claude Code.

## Skills Included

| Skill | Command | Focus |
|---|---|---|
| `council-of-rome` | `/council` | Senate orchestration — convene multiple magistrates |
| `censors-decree` | `/censor` | Architecture, code quality, structural integrity |
| `tribunes-appeal` | `/tribune` | UX, accessibility, user advocacy |
| `praetors-inquisition` | `/praetor` | Security, compliance, legal exposure |
| `augurs-reading` | `/augur` | Strategy, market timing, competitive risk |
| `legatus-campaign` | `/legatus` | Operations, DevOps, deployment readiness |

## Usage

Each skill triggers automatically when relevant, or invoke directly via slash command.

See the [root README](../../README.md) for full documentation.
